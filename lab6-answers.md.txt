3. Why is Delete a small form sent by post, while Edit is a link?
Clicking Edit only allows you to read and display existing data so you can view it in a form, while Delete is a post form because deleting permanently changes or destroys database records.
4. Someone opens deliveries.php?date=' OR '1'='1 on my site.
Instead of returning all deliveries from the database, the query runs safely and simply returns no record, because there is no delivery whose actual date column literally equals the text string ' OR '1'='1.
What happens, and why does my prepared statement not run it as SQL?
A prepared statement compiles the SQL query structure first (SELECT ... WHERE date = ?) before inserting user input. When the parameter is bound later, MySQL treats the entire input strictly as a literal data value rather than executable SQL code.
